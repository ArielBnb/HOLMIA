# Illustrative property photo

Source: https://images.unsplash.com/photo-1600596542815-ffad4c1539a9?w=1000&q=85

The original JPEG bytes are encoded in propertyIllustration.js as a data URI and bundled as a generic illustration for existing listings whose image_url is null. It is not asserted to depict any specific property. The interface labels it Illustrative photo. Real Supabase image_url values take precedence.

No external request for this fallback is required at runtime.
