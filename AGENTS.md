# HOLMIA

React Native et Expo SDK 58, JavaScript uniquement.

- Conserver App.js et la structure src demandée par le cahier des charges.
- Ne pas ajouter Expo Router ou TypeScript sans décision de l’équipe.
- Utiliser npx expo install pour les dépendances natives compatibles.
- Supabase PostgreSQL et Supabase Auth sont prévus en mission 2.
- Ne jamais versionner de secrets, de fichiers .env ou de clés service_role.
- Vérifier npm run lint, npx expo-doctor et les bundles Android/iOS avant publication.
- Les tests sur appareil sont distincts des contrôles de bundling.
